# 🎧 Audio Hunter Bot

Телеграм-бот для поиска и воспроизведения звуков, а также для развлечения с помощью мини-игры "Угадай звук".

## ✨ Основные возможности

### 🔍 Поиск звуков
Бот предлагает два режима поиска:
1.  **Локальная база данных** 📂:
    *   Поиск по категориям: **Животные** 🦁, **Транспорт** 🚗, **Предметы** 🔔.
    *   Быстрый доступ к популярным звукам.
2.  **Поиск в интернете** 🌐:
    *   Интеграция с сайтом [zvukogram.com](https://zvukogram.com/).
    *   Дополнительный источник [Freesound](https://freesound.org/) при настройке API-ключа.
    *   Поиск любых звуковых эффектов по ключевым словам.
    *   Выбор результата кнопкой: скачивается только выбранный звук.
    *   Повторная отправка через сохранённый Telegram `file_id`, без повторного скачивания.

### 🎮 Мини-игра "Угадай звук"
Встроенное **Telegram Mini App** приложение, где пользователю нужно угадывать источник звука:
*   Слушайте случайный звук 🔊.
*   Выбирайте правильный вариант из предложенных картинок 🖼️.
*   Получайте мгновенную обратную связь.

### 🦖‍ Панель администратора
Специальные функции для администратора бота:
*   📥 **Загрузка контента**: Добавление новых звуков и картинок прямо через чат в локальную базу.
*   📊 **Статистика**: Просмотр топ пользователей по активности.
*   📢 **Рассылка**: Отправка сообщений с формой обратной связи всем пользователям.

*   **Python 3.12+**
*   **Aiogram 3.x** — Асинхронный фреймворк для Telegram Bot API.
*   **FastAPI** — Бэкенд для Web App (Mini App).

*   **Docker & Docker Compose** — Для контейнеризации и удобного развертывания.

## 🛠️ Установка и запуск

### Предварительные требования
*   Установленный **Docker** и **Docker Compose**.
*   Токен бота от [@BotFather](https://t.me/BotFather).

### ⚙️ Конфигурация
1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/ваш-пользователь/animal_voice_bot.git
    cd animal_voice_bot
    ```

2.  Создайте файл `.env` на основе `.env_example` или заполните его своими данными:
    ```env
    BOT_TOKEN=ваш_токен_бота
    BOT_ADMIN_USER_ID=id_администратора
    SEARCH_RESULT_COUNT=5
    DATABASE_PATH=data/sounds_database.db
    TOP_USER_REQUESTS_COUNT=5
    FEEDBACK_MESSAGE="Текст сообщения для обратной связи"
    WEBAPP_URL=https://ваш-домен.com
    FREESOUND_API_KEY=
    WEB_SOUND_SOURCE=both
    ```
    > **Примечание:** `WEBAPP_URL` — это HTTPS ссылка на ваше развернутое FastAPI приложение (для работы Mini App).

### Поиск звуков в сети

`FREESOUND_API_KEY` необязателен. Получите ключ на [странице регистрации приложения Freesound](https://freesound.org/apiv2/apply/) и добавьте его в окружение бота. Без ключа используется только Zvukogram. После изменения окружения перезапустите бот; для Docker выполните `docker compose up -d --build`.

При подключении Freesound оба источника опрашиваются параллельно. `SEARCH_RESULT_COUNT` ограничивает общее количество результатов (от 1 до 20); результаты источников чередуются. Если один источник недоступен, бот показывает выдачу другого и сообщает об этом.

`WEB_SOUND_SOURCE` выбирает источник: `both` (по умолчанию) — оба источника, `freesound` — только Freesound, `zvukogram` — только Zvukogram. Для проверки Freesound установите `WEB_SOUND_SOURCE=freesound` и перезапустите бот. В этом режиме Zvukogram не опрашивается, в том числе при ошибке Freesound; требуется `FREESOUND_API_KEY`.

Распространённые русские запросы («лай собаки», «шум дождя», «пение птиц») переводятся локальным словарём. Остальные передаются Freesound как есть; для них можно использовать английские слова. Словарь находится в `src/services/web_sound_search.py`.

Freesound отправляется в виде MP3-превью; оригиналы не скачиваются и OAuth не требуется. В подписи сохраняются автор, лицензия и ссылка на источник. Условия использования конкретного звука указаны на странице источника. [Документация API Freesound](https://freesound.org/docs/api/resources_apiv2.html).

Кэш `file_id` хранится в таблице `web_sound_cache` существующей SQLite-базы и привязан к ID бота. Таблица создаётся автоматически; новая база не нужна. Кнопки действуют 30 минут, до нового поиска или перезапуска бота, и доступны только пользователю, выполнившему поиск. Размер скачиваемого файла ограничен 20 МиБ. HTTP-сессия переиспользуется, TLS проверяется; таймаут запроса — 30 секунд, подключения — 5 секунд, чтения — 15 секунд.

### ▶️ Запуск через Docker (Рекомендуется)
Полностью готовое окружение поднимется одной командой:
```bash
docker compose up -d --build
```

### � Локальный запуск (для разработки)
Если вы хотите запустить бот без Docker:

1.  Создайте виртуальное окружение:
    ```bash
    python -m venv .venv
    # Windows
    .venv\Scripts\activate
    # Linux/MacOS
    source .venv/bin/activate
    ```
2.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
3.  Запустите бота:
    ```bash
    python src/main.py
    ```
4.  Для работы Mini App запустите веб-сервер отдельно:
    ```bash
    uvicorn src.sound_game:app --reload
    ```

### Проверка изменений

Дополнительные тестовые зависимости не нужны: используются `unittest` и пакеты из `requirements.txt`.

```bash
python -m compileall -q src
PYTHONPATH=src python -m unittest discover -s tests -p 'test_web_sound*.py' -v
```

Тесты используют временную SQLite-базу, локальный HTTP-сервер и подменяют обращения к Telegram. Реальные токены и API-ключи для этих тестов не нужны. Для ручной проверки нажмите «Найти в сети», введите запрос, выберите звук, повторно выберите его и проверьте поиск без результатов. С настроенным ключом Freesound проверьте подпись с автором и лицензией.
